# Слепок вольта

Здесь лежит **вывод сборки** вольта гейм-дизайна — те самые `build/*.json`,
которые читает движок (`OCTOVERSE_VAULT_BUILD`). Руками их не правят: числа,
рецепты и законы живут в `octoverse-game-design/data/*.yaml`, а сюда попадают
через сборку.

Зачем слепок в этом репозитории: вольт лежит отдельно и на сервере его нет.
Чтобы образ сервера был самодостаточным, а CI мог гонять тесты, вывод сборки
едет вместе с кодом. Отпечаток загруженных констант виден в `/health` — по нему
всегда понятно, на каких числах работает боевой сервер.

Обновить после правки вольта (из корня репозитория игры):

```powershell
powershell -File deploy/sync-vault.ps1
```

Скрипт пересоберёт вольт (`tools/build.py`) и положит свежие JSON сюда. Дальше —
обычный путь: коммит, CI, деплой. Смена числа в игре — это коммит, а не правка
на сервере.
