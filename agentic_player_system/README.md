# Agentic player system — ИИ-граждане (D-224)

Агенты на языковой модели, которые живут в мире на правах игроков. У агента
обычный аккаунт, он платит устройством за сессию и действует **только через тот
же WebSocket, что и клиент** (`/session/ws`). Движок и база ему недоступны:
что отказано игроку — отказано и ему, и каждый отказ попадает в журнал.

Зачем: движение в экономике на альфе и постоянная проверка пути игрока на
стопперы. У агента есть инструмент «заявить о дефекте» — заявки собираются в
отдельный список панели.

## Запуск

Нужен работающий игровой сервер (`backend/`, см. корневой README).

```bash
uv pip install --python backend/.venv/Scripts/python.exe -e "agentic_player_system[dev]"
```

```bash
cp agentic_player_system/.env.example agentic_player_system/.env
```

В `.env` — логин и пароль админа панели (в игре админской роли нет, вход
только отсюда), адрес игрового сервера и ключ провайдера (`APS_LLM_API_KEY`).
Ключ можно и не писать в `.env`, а ввести в панели — тогда он хранится в SQLite
и главнее значения из окружения.

```bash
cd agentic_player_system && ../backend/.venv/Scripts/python.exe -m aps
```

Панель: <http://127.0.0.1:8100>. Во вкладке «Провайдер» — base URL
OpenAI-совместимого API, модель и ключ (DeepSeek: `https://api.deepseek.com/v1`,
`deepseek-chat`). Ключ хранится только в SQLite на сервере и наружу не отдаётся.

## Агент

Создаётся в панели: имя в игре, почта и пароль аккаунта (если аккаунта нет —
агент зарегистрируется сам у указанной двери), характер, цель, частота хода,
дневной бюджет токенов, число вызовов за ход. «Пуск» включает агента, «Ход
сейчас» — внеочередной ход, «Журнал» — лента: наблюдения, действия, отказы,
мысли, заявки о дефектах, расход токенов.

Ход агента: `look` → модель с инструментами `act`, `help`, `read`, `remember`,
`report_bug`, `finish` → не больше N вызовов → заметки (единственная память
между ходами) обновлены.

Защита от сжигания денег — свойство раннера, не мира:

- дневной бюджет токенов — по достижении агент ждёт следующего дня (UTC);
- одно и то же действие отказано четыре раза подряд за ход — пауза на пять ходов;
- ошибка провайдера или сервера — повтор через пять минут.

Справочник команд читается из `backend/src/api/session.py` при старте (имя,
аргументы, докстринг) и кэшируется в базе — в деплое без исходников
используется кэш.

## Выкладка

На боевом сервере панель — служба `agents` состава и домен
`agents.everse.life`: см. `DEPLOY.md`, раздел «ИИ-граждане».

## Первая проверка

Два агента: первому — цель «основать новый город», второму — «переехать в
новый город и заложить там корабль». Журналы и список дефектов покажут, где
игрок упрётся.

## Устройство

| Файл | Что |
|---|---|
| `aps/game.py` | WebSocket-клиент игры, плата устройством (Argon2id, как в `frontend/src/pow.ts`) |
| `aps/commands.py` | справочник команд из `session.py` через `ast` |
| `aps/llm.py` | `chat/completions` с инструментами у любого OpenAI-совместимого провайдера |
| `aps/brain.py` | один ход агента |
| `aps/runner.py` | расписание, бюджет, пауза при зацикливании |
| `aps/store.py` | SQLite: агенты, журнал, дефекты, расход |
| `aps/web.py`, `aps/static/index.html` | панель |

Тесты: `cd agentic_player_system && ../backend/.venv/Scripts/python.exe -m pytest -q`.
