# OctoVerse — клиент (альфа)

React + TypeScript (D-139). Цель — весь функционал альфы (D-103): экономика,
общество и кредит целиком, потому что проверять их частями бессмысленно.

Компоновка — четыре постоянные зоны (D-050): верхний баннер; **левый сайдбар**
с тем, что работает через Сеть (персонаж, инвентарь, дела, торговля, знания,
хозяйство, сводка мира) — доступен всегда, хоть с дороги; **основное окно** с
табами карта · локация · кружки; **нижняя полоса** — живой чат локации. Счета
за быт живут в сайдбаре потому, что это деньги, а не материя (D-149), а
управление городом — в администрации, потому что власть присутственна (D-155).

Карта — граф, нарисованный графом, с четырьмя слоями показа: космос · планета
· город · локация. Мир при этом остаётся одним графом: узел верхнего слоя —
представитель группы, клик раскрывает её, «идти» работает в любой узел — в
несоседний маршрут строится сам и идётся отрезками (автопуть, D-045).
Пустые слои скрыты: «локация» появится с первыми субузлами. Слой «город»
показывает свой город, если стоишь в нём, иначе — последний раскрытый либо
первый существующий: города публичны (D-097). Точка
ползёт по ребру, пока идёшь; дошёл — «Войти», и открывается сцена локации.
Присутственные табы в пути недоступны: тебя нет в узле.
Организующий принцип — сайдбар удалённое, основное окно присутственное: игрок
усваивает устройство мира, просто пользуясь интерфейсом.

## Про оформление

Визуальный язык — отдельная работа дизайнера (D-049, D-072), а пилотный экран
проверяет непроверенное решение: **обозначать интерактивность без цвета**
(D-055, D-056). Поэтому оформление намеренно никакое — один шрифт, одна рамка,
никакого цветового кодирования смысла. Функциональность настоящая, вид —
временный.

## Запуск

Нужны три процесса. Из корня репозитория:

```bash
docker compose up -d
```

```bash
cd backend && .venv/Scripts/python -m alembic upgrade head
```

Стартовый мир — столица Терры с администрацией, свободными участками и
угольной шахтой в двадцати минутах за воротами, плюс два игрока, Тэрн и Хём
(Тэрн — президент города):

```bash
cd backend && .venv/Scripts/python -m src.seed
```

Часы мира. Без него партии не заканчиваются и ордера не истекают:

```bash
cd backend && .venv/Scripts/python -m src.worker
```

Сервер:

```bash
cd backend && .venv/Scripts/python -m uvicorn src.api.app:app --port 8000
```

Клиент:

```bash
cd frontend && npm install && npm run dev
```

Адрес сервера по умолчанию — тот же хост, откуда открыта страница, порт 8000.
Открыл `http://localhost:5173` — клиент идёт на `localhost:8000`, открыл с
телефона `http://192.168.1.4:5173` — на `192.168.1.4:8000`. Перекрывается
переменной `VITE_API`, когда сервер стоит не рядом с клиентом.

## Игра по локальной сети

Оба процесса уже слушают все интерфейсы: `vite` — через `server.host` в
[vite.config.ts](vite.config.ts), сервер — через `--host 0.0.0.0`. Играющим
даётся адрес вида `http://192.168.1.4:5173` (свой посмотреть `ipconfig`).

Сервер пускает браузер с любого адреса частной сети и из `26.0.0.0/8` — это
сеть Radmin VPN, через которую играют не соседи по комнате (`allowed_origin_regex`
в [settings.py](../backend/src/settings.py)). Из интернета так не зайти, но
диапазон Radmin частным не является: он просто не маршрутизируется, и защищает
там **список участников сети VPN**, а не топология.

Настоящего опознания нет до Э7 (D-027): любой, кто открыл адрес, называется
любым именем и распоряжается чужим счётом. Поэтому поднимать игру стоит только
в сети, где все свои, — и в комнате Radmin тоже только со своими.

Windows по умолчанию не пускает входящие соединения в **общедоступной** сети.
Один раз, от администратора:

```powershell
New-NetFirewallRule -DisplayName "OctoVerse dev" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 5173,8000 -Profile Any -RemoteAddress LocalSubnet
```

## Что клиент показывает честно

| Что видно | Почему это важно |
|---|---|
| Устойчивости свода нет ни в одном ответе, а признак не меняется, пока не ударишь | Скрытое число не «спрятано в интерфейсе» — его физически нет; переспрашивать бесполезно, иначе среднее выдало бы его (D-143) |
| Плата устройства считается в браузере и занимает заметное время | Налог на масштаб: тысяча персонажей — тысячекратная нагрузка на железо (D-110) |
| Прогноз качества показан числом **до** того, как потрачены материалы | Без точного числа игрок не свяжет действие с результатом (D-092) |
| Партия идёт после закрытия вкладки | Длительное действие живёт в журнале заданий, а не в браузере |
| «Купить» работает только стоя в узле, ордером распоряжаются откуда угодно | Материя требует присутствия, информация — нет (D-047) |
| Купленное лежит в терминале и забирается отдельно | Вещи перемещаются только физически |
| У монеты не качество, а **проба и клеймо**, и пробу при чеканке можно занизить | Монета — предмет, описанный содержанием металла; порча монеты не баг, а решение эмитента, за которое платит его клеймо (D-016) |
| Сеют семенами, а не урожаем, и у партии видна **сила**; уборка предлагает «с отбором» и «без» | Семена — имущество, агротехника — знание, и преимущество фермера растёт из них, а не из уровня. Без отбора фонд вырождается сам (D-057, D-067) |
| Без агротехники грядка показывает «листья вялые», с агротехникой — «плодородие 55 из 45 нужных» | Знание превращает угадайку в решённую задачу. Запрета сеять нет: новичок упирается не в стену, а в собственное невежество — и оно лечится (D-057) |
| Пул энергии и счета за быт лежат в сайдбаре, а не в каждой локации | Это деньги, а не материя: платят откуда угодно. Раздел «владения» появляется только у того, у кого владения есть (D-149) |
| Узел, за который не заплачено, пишет «отключён», и станки в нём не работают | Счётчик — такое же условие работы, как сам станок; отобрать узел за долг движок не вправе, это дело суда (D-149) |
| Станок показан с пометкой «занят», а не молча отказывает | За станком работает один: мест в мастерской ровно столько, сколько станков, и свой станок дома — способ не стоять в очереди (D-150) |
| В администрации житель видит законы, а власть — кнопки, и только придя туда | Законы, по которым живёшь, обязаны быть видны всем; правит их тот, у кого есть право, и решает он это в ратуше, а не из-за океана (D-154, D-155) |
| Должность собирается из галочек: «министр экономики» — это пошлины и панель | Право дробится до одного закона, а название посту придумывает город. Список законов приходит из вольта, и новый появится в галочках сам (D-155) |
| Панель города открыта всем, казна по статьям — по праву | Спорить с властью без цифр нечем; персонального нет ни у кого (D-124, D-140) |
| Новый персонаж входит с нулём на счету, а подъёмные приходят из казны города | Мир денег не выдаёт — это была бы эмиссия. Город платит сам, потому что новый житель платит налоги (D-153) |
| Погибнув, игрок видит не «вы умерли», а список принтеров с ценой и сроком | Наказание уже случилось и оно экономическое; бесплатная дверь столицы в списке всегда, поэтому из игры нельзя выпасть (D-028, D-033) |
| У каждого выхода с карты подписана цена в выносливости | Дорога стоит не только времени: закрыть вкладку и «прийти бесплатно» больше нельзя, а повозка эту цену обнуляет (D-147) |
| Галочка «на автомате» меняет прогноз: вдвое быстрее, свой потолок, но со счётом за энергию | Два уклада вместо лестницы улучшений: ремесло адаптивно и бесплатно по энергии, промышленность ровна и платит по счётчику (D-035, D-058) |
| Буровая пишет «бункер полон, машина стоит» и «угля на 20 ч» | Это не ошибки, а обязательства предприятия: без углевоза и возчика капитал не работает (D-115) |
| Бронь ставится издалека, а кнопка «Выкупить» есть только в том узле, где товар | Единственное исключение из «купить только стоя здесь» — и оно не отменяет географию, а позволяет её планировать (D-047) |
| В сводке мира у части инвариантов написано «ждёт транспорта», а не «в порядке» | Зелёная галочка на непроверенном хуже отсутствия проверки: отсутствие механики должно быть заметно (60-meta/04) |
| Сцена локации появляется **только по приходу** и только та, что здесь есть | Пока идёшь, тебя нет в узле; жила даёт забой, терминал — рынок (D-107) |
| Панель называется именем станка — «Плавильная печь», а не «мастерская», — и показывает только то, что делается на нём | Станок задаёт, чем место является (D-106): три станка во дворе это три разных дела, а не один список, из которого половина откажет |
| Разведка живёт на карте, и цель зависит от слоя: в городе ищут участок, на планете — место под город или жилу названной породы | Искать новое место логично там, где карта видна. Названная порода попадается тем реже, чем она дороже, — иначе все искали бы только самое дорогое (D-152) |

## Устройство

```
src/
  api.ts        две поверхности: публичное чтение и сессия клиента
  pow.ts        плата устройства в браузере (Argon2id, hash-wasm)
  App.tsx       каркас: баннер, сайдбар, табы основного окна
  panels/       Sidebar · World · GraphMap · Circles · Chat · Farm ·
                Nursery · Mine · Rig · Workshop · Kitchen · Library ·
                Market · Mint · Place · Holdings · Admin · Printer
                (Admin — в локации с администрацией; Workshop — по одной
                панели на станок, разведка живёт на карте)
```

Стартовая карта — город из локаций: ядро с Принтером Предтеч, Библиотека,
торговый двор и администрация в первом кольце, кузнечный двор и три свободных
участка во втором, забой у стены и выход из города, за которым лежат угольная
шахта и пойма — по двадцать минут по дороге. Дальше карта растёт разведкой, а
не патчем (D-152).

Действия идут **только** через `/session/ws`. Удобного REST для «сделать удар»
нет и не будет: он превратил бы добычу в скрипт (60-meta/01-anti-cheat).
